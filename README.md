# Security Hacks 🔐

> 名前はちょっと物騒。中身はセキュリティの手法集。

**Security Hacks** は、セキュリティに関する手法・小技・知見を集めて整理するためのリポジトリです。

「これ、どうやるんだっけ？」「どういう仕組みで起きて、どう防ぐんだっけ？」を、あとから見返せる形で残していきます。

ここでいう *Hacks* は、不正アクセスというより **工夫・テクニック・試行錯誤** のニュアンス。とはいえ、攻撃の仕組みを理解することもセキュリティの大事な一部です。

## ここにまとめるもの

- **仕組みの理解** — 脆弱性、攻撃手法、認証・認可、暗号など
- **調査・検証** — 情報収集、ログ分析、検証環境での再現手順
- **防御・対策** — 設定の見直し、検知、ハードニング、インシデント対応
- **ツール・小技** — コマンド、スクリプト、便利な使い方、ハマりどころ
- **学習メモ** — 気になった技術、調べたこと、参考資料

特定の分野に絞りすぎず、役に立ちそうなものを少しずつ増やしていく予定です。

## メモの方針

きれいな解説書よりも、**あとで自分が使えること** を優先します。

できるだけ次の情報を残します。

1. **何をする手法か** — 目的と概要
2. **どこで使えるか** — 前提条件と対象範囲
3. **どう試すか** — 手順、コマンド、設定例
4. **何がわかったか** — 検証結果、注意点、失敗例
5. **どう守るか** — 必要に応じて対策や検知方法
6. **参考資料** — 公式ドキュメントや関連リンク

すべてのメモがこの形式とは限りません。まず書く、あとで整える。

## 注意事項

このリポジトリは **学習・研究・防御・正当な検証** を目的としています。

- 検証は、自分が管理する環境または明示的に許可された環境でのみ行ってください。
- 第三者のシステムに対して、無断で手法やツールを使用しないでください。
- 認証情報、秘密鍵、個人情報などはコミットしないでください。
- 記載内容は環境や時期によって変わります。実際に使う際は一次情報も確認してください。
