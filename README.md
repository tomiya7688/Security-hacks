# Security Hacks 🔐

> **名前はちょっと物騒。中身はちゃんと役立つセキュリティ手法集。**

**Security Hacks** は、セキュリティの基礎・実用的な手法・ちょっと便利な小技・よくある疑問を、**親しみやすい日本語**でまとめるリポジトリです。

「最初から教科書を全部読む」のではなく、「これって何？」「今ちょっと確認したい！」と思ったときに、**読んで、試して、理解できる**場所を目指しています。

ここでいう *Hacks* は、不正アクセスではなく、**工夫・テクニック・試行錯誤** というニュアンス。攻撃の仕組みを学ぶこともありますが、目的は理解と防御です。

## 🧰 どんな内容を集める？

- **ちいさな教科書** — 最低限の用語、考え方、仕組み
- **実用的な手順** — コマンド、設定例、調査・検証の流れ
- **小技・Tips** — 忘れやすいオプション、よくある落とし穴
- **Q&A** — 「それってどういうこと？」を短く解決
- **攻撃と防御の理解** — 何が問題で、どう防ぎ、どう確かめるか

「難しい言葉を並べる」より、**ひとつ読んだら、ひとつ役に立つ**ことを大切にします。

## ✍️ 記事の方針

1. **まず結論** — 何のための記事で、何ができるのか。
2. **やさしく説明** — 初めて出る用語は、なるべく一言で説明。
3. **実際に試せる** — 前提条件、コマンド、設定例を書く。
4. **結果の見方も書く** — どこを見て、どう判断すればよいか。
5. **できないことも明記** — 一つの確認だけで「安全」と断定しない。
6. **根拠を残す** — 可能な限り公式ドキュメントや参考資料を添える。

完成された百科事典より、**少しずつ育つ、使えるノート兼ミニ教科書**を目指します。

## ⚠️ 安全に試すために

このリポジトリは**学習・研究・防御・正当な検証**のためのものです。

- 検証は自分で管理している環境、または明示的に許可された範囲で行ってください。
- 他者のシステムに対して、無断で診断・攻撃・探索をしないでください。
- APIキー、パスワード、秘密鍵、個人情報などはコミットしないでください。
- 手法や設定は環境・時期によって変わります。重要な作業では公式の一次情報も確認してください。
