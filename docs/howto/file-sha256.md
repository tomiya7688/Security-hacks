# ダウンロードしたファイル、途中で変わっていない？

> **便利そうなツールをダウンロード。でも、これって本当に配布元が用意したファイルなのかな？**

インストールする前に「途中で壊れたり、別の内容に変わったりしていないか」を確かめたいことがありますよね。

そんなとき、**ファイルの中身から計算できる、長い目印のような文字列**が役立ちます。

これを **「ハッシュ値」** といいます。ハッシュ値を作る計算方法のひとつが **SHA-256（エスエイチエー・256）** です。

## どんな仕組み？

同じ中身のファイルからは、同じハッシュ値が計算されます。中身が少しでも変われば、通常は別の値になります。

SHA-256で計算した結果は、**0〜9とa〜fを並べた64文字の値**です。

配布元が公開している値と、手元で計算した値を比べれば、**同じ内容かどうかを高い信頼度で確認**できます。

ただし、**比較する相手の値そのものが、信用できる場所から手に入ったこと**が前提です。

## 実際に確かめてみよう

たとえば、手元に `download.zip` というファイルがあるとします。次のコマンドは、このファイルを読み取って値を計算します。

**Linux**

```sh
sha256sum ./download.zip
```

**macOS**

```sh
shasum -a 256 ./download.zip
```

**Windows（PowerShell）**

```powershell
Get-FileHash -Path .\download.zip -Algorithm SHA256
```

ファイル名は手元のものに置き換えてください。コマンドが何をしているかというと、**ファイルの中身を読み、先ほどの64文字の目印を表示する**だけです。

## 結果をどう読めばいい？

公式の配布ページなどにある **SHA-256 の値**と、出てきた値を比べます。大文字・小文字の違いは気にしなくて大丈夫です。

| 結果 | どうすればいい？ |
| --- | --- |
| **一致した** | 公開された値に対応する内容と一致したと考えられます |
| **違った** | 実行せずに確認。破損、バージョン違い、別のファイルなどが考えられます |
| **比較する値がない** | 手元の値を計算しただけでは、正しいファイルか判断できません |

## 値が同じなら絶対に安全？

**いいえ。** 同じ内容だと確かめられても、そのファイルが危険な動作をしないことまではわかりません。

たとえば、配布元のWebページとファイルの両方が書き換えられていたら、両方の値がそろってしまう可能性があります。

誰が公開したファイルなのかを確かめるために、配布元が別途用意している**作成者を確認するための仕組み**を使うことがあります。これを **「デジタル署名の検証」** といいます。

## うまくいかなかったら

- **ファイルが見つからない**：ファイル名と、コマンドを実行している場所を確認する。
- **値が一致しない**：同じバージョン・同じOS向けのファイルと比べているか確認する。
- **同じ名前なのに値が変わる**：配布元がファイルを更新したり、毎回別の内容を生成したりしている場合があります。

## まとめ

**これでわかること：** 信頼できる場所で公開された値と、手元のファイルの中身が一致するかどうか。

**これだけではわからないこと：** ファイルが無害かどうか、配布元が本物かどうか。
