# ダウンロードしたファイルのSHA-256を確認する

> **所要時間：1分 / 必要なもの：OS標準のコマンド**

「ダウンロードしたファイルが、配布元の案内と同じものか？」をチェックする小技です。

## SHA-256って？

ファイルから計算する、長い文字列（ハッシュ値）のことです。**ファイルの中身が少しでも変わると、通常は違う値**になります。

ただし、**ハッシュ値が一致しても「配布元そのものが本物」と証明できるわけではありません。** 比較する正解の値をどこで入手したかも重要です。

## やってみよう

たとえば `download.zip` のハッシュ値を確認するなら：

**Linux**

```sh
sha256sum ./download.zip
```

**macOS**

```sh
shasum -a 256 ./download.zip
```

**Windows（PowerShell）**

```powershell
Get-FileHash -Path .\download.zip -Algorithm SHA256
```

ファイル名は、実際にダウンロードしたものに置き換えてください。

## 結果の見方

出てきた64桁の16進数を、**公式の配布ページなどが提示する SHA-256 の値**と比較します。

- **一致**：そのハッシュ値に対応する内容のファイルだと確認できた
- **不一致**：ファイルの破損、バージョン違い、別ファイルなどの可能性。**実行せず、入手元から確認し直す**
- **比較元がない**：自分で計算した値だけでは、正しいファイルかどうかは判断できない

配布元がデジタル署名の検証手順を用意しているなら、**署名も検証**するのがおすすめです。ハッシュ比較だけでは配布ページとファイルが一緒に改ざんされたケースを見抜けません。

## よくあるつまずき

- **ファイルが見つからない**：今いるディレクトリとファイル名を確認する。
- **文字列が一致しない**：見ているのが同じバージョン・同じOS向けの配布物か確認する。
- **ダウンロードのたびに値が変わる**：動的に生成されるファイルでは、同じ名前でも内容が異なることがあります。
