# AI開発ツールでHTMLを開くだけで、秘密のファイルが読まれる？（EMBRACE）

> **研究公表日：** 2026-10-29（Forever Security）  
> **内容確認日：** 2026-10-31（日本時間）  
> **対象：** Cursor、GitHub Copilotデスクトップアプリ、Claude Desktop、OpenAI Codexデスクトップアプリ、Visual Studio Codeの**内蔵ブラウザー・プレビュー機能**  
> **情報の性質：** 研究者による5製品の脆弱性実証・公開。各製品で欠陥と修正状況が異なる

> **「AIにコードを見てもらうだけなのに、なぜSSH鍵や `.env` ファイルまで盗まれることがあるの？」**
>
> **問題はAIの回答だけではありません。** 開発ツールの中にある「WebページやHTMLの見た目を確認する画面」が、普通のブラウザーより強い力を持っていたことが原因です。ただし、**5製品すべてで同じ攻撃が成功するわけでも、すべての利用者が被害に遭ったわけでもありません。**

## 何が起きた？

2026年10月29日、Forever Securityの研究者Gal Weizmanが、5つのAI開発ツールに組み込まれたブラウザーの問題を公開しました。

これらのツールには、Webページを表示したり、作ったHTMLを確認したりする機能があります。普通のブラウザーは、怪しいページがPC内の別のファイルを勝手に読むことや、PC上でコマンドを実行することを制限しています。

ところが、AIとの連携を便利にするため、**「ページの内容をAIへ渡す」「手元のファイルを表示する」「タブのURLをAIへ伝える」**などの機能が追加され、守るべき境界を越えられる場合が見つかりました。

研究チームは、この共通した問題の型を**EMBRACE**と名付けました。正式な脆弱性番号（CVE）をまとめて付けた名称ではなく、**複数の異なる欠陥を研究者が分類した呼び名**です。

## どんな危険が見つかった？

研究者の実験で示された問題は、大きく3種類あります。

| 製品 | 実証された問題 | 何が危ない？ |
| --- | --- | --- |
| **OpenAI Codexデスクトップアプリ** | 内蔵プレビューで開いたローカルHTMLが、許されないはずの別のファイルまで読める | SSH秘密鍵や設定ファイルを読み取られるおそれ |
| **Visual Studio Code** | ローカルHTML内のバックグラウンド処理が、表示中のページにかかるファイル制限をすり抜ける | プロジェクト外のファイルを読み取られるおそれ |
| **Claude Desktop** | 同種のローカルファイル読み取りの問題 | 開発端末の秘密情報を読み取られるおそれ |
| **Cursor** | 悪意あるWebページから、AIへの隠れた指示を送り込める | 条件が合えば、AI経由でPC上のコマンド実行につながる |
| **GitHub Copilotデスクトップアプリ** | ページが実際の接続先とは違うURLを内蔵ブラウザーに表示させられる | 本物のログイン画面と誤認させるおそれ |

この表は**研究者による実証結果**です。今すぐ全員のファイルが盗める、という意味ではありません。また、ブラウザーの欠陥が5製品で完全に共通していたわけではありません。

## なぜ「HTMLを開くだけ」で危ないの？

例えば、ほかの人の作ったプロジェクトをダウンロードして、AIに「中のテスト結果を見て」と頼んだ場面を想像してください。

```text
信頼できないプロジェクト
    ↓
「結果を見たい」→ AIがHTMLのプレビューを提示
    ↓
開発ツールの内蔵ブラウザーで表示
    ↓
本来は表示だけのはずが、別のローカルファイルを読めてしまう
    ↓
ファイルの中身が外部へ送られる可能性
```

**SSH鍵**は別のコンピューターへ安全にログインするための秘密情報です。**`.env` ファイル**には、アプリが使うパスワードやサービスの秘密の鍵が置かれることがあります。

研究者は、自分たちが用意した検証環境で、SSH鍵、`.env`、開発用トークンなどを読み取り、外部送信する流れを実証しました。これは**「本物の利用者から大規模に盗まれた」と確認された報告ではありません**。

Claude DesktopとVS Codeでは、画面の裏で別に動く処理（**Web Worker**）に、表のページと同じ制限が適用されていなかったと報告されています。Codexでは、研究者の確認したプレビューに、そもそも十分なファイル読み取りの制限がなかったと説明されています。

**大切なのは、「AIが悪い命令に従ったか」とは別に、表示用の仕組みそのものが危険になり得ることです。**

## 修正状況は？（2026年10月31日確認）

| 製品 | 公表資料で確認できる状況 |
| --- | --- |
| **Codexデスクトップアプリ** | 研究者は**10月29日時点で未修正**と報告。OpenAIは海外メディアに、問題を認識し対応中と説明 |
| **VS Codeの対象プレビュー機能** | 研究者は**10月29日時点で未修正**と報告。Microsoftは「信頼した作業領域」に関する問題として報告を受理しなかった、と研究者は説明 |
| **Cursorの対象内蔵ブラウザー** | 研究者によれば**10月1日に修正済み**。修正済みの正確な最小バージョンは公表資料から特定できない |
| **GitHub Copilotデスクトップアプリ** | 研究者によれば**10月13日公開の1.1.29で修正**。1.1.27で問題を確認 |
| **Claude Desktopの関連問題** | 別の研究チームNoma Labsは、同様のプレビュー問題「SneakPeek」が**1.30096.1以降で修正**されたと報告。ただし、Forever Securityの実証した条件まで同一に解消されたかは、この資料だけでは確定できない |

**「未修正」は研究者が10月29日に公開した時点の状態です。** 10月31日以降の更新や、製品提供元が別の評価をしている可能性があります。上表だけで現在の最新版の安全性を断定しないでください。

また、**Codexのデスクトップアプリと、Codex CLI・APIは同じものではありません。** この研究は内蔵ブラウザーを調べたもので、CLIやAPIにも同じ問題があると確認されたわけではありません。**GitHub Copilotデスクトップアプリと、VS Codeに入れるCopilot拡張機能**も混同しないでください。

## 今、何をすればいい？

### 1. 使っている製品・機能を確認する

開発ツールの「バージョン情報」から、製品名とバージョンを確認してください。Cursor、GitHub Copilot、Claude Desktopは**公式の更新方法で最新版に更新**しましょう。

ただし、**最新版になったことだけで、過去に不審なHTMLを表示した際の情報流出がなかったと判断できるわけではありません**。

### 2. 信頼できないHTMLを内蔵プレビューで開かない

特に研究者が未修正と報告した**CodexデスクトップアプリとVS Code**では、入手元の分からないリポジトリのHTML、レポート、プレビューへのリンクを安易に開かないでください。

AIが「このファイルを開いて確認してください」と案内した場合も、**そのファイルの中身を誰が作ったのか**を考えましょう。AIがリンクを示しただけでは、ファイルの安全性は保証されません。

やむを得ず未知のプロジェクトを検証するなら、重要な認証情報を持ち込まない**隔離された作業環境**などを検討してください。「別のブラウザーで開けば何をしても安全」というわけでもありません。

### 3. 開発端末に置く秘密情報を減らす

SSH秘密鍵、`.env`、APIキー、クラウド認証情報などを必要以上に置かないようにします。可能なら、利用範囲が狭く、有効期限の短い鍵やトークンを使います。

実際に不審なプレビューを開いた可能性がある場合は、**アプリを閉じるだけで調査が終わるわけではありません**。組織ならセキュリティ担当者と相談し、アクセス記録の確認や必要な認証情報の無効化・再発行を検討してください。

**秘密鍵の中身や `.env` の内容を確認用コマンドの実行結果としてSNSや公開Issueに貼り付けないでください。**

## どこまで分かっている？

- **分かっていること：** Forever Securityが5製品それぞれについて、内蔵ブラウザーの異なる問題を研究環境で示した。
- **研究者の報告：** 公開時点でCodexとVS Codeは未修正、CursorとCopilotの対象問題は修正済み。
- **別の研究報告：** Claude Desktopの関連するプレビュー問題にはNoma Labsが修正版を報告している。
- **分からないこと：** 一般利用者の実際の被害件数、すべてのOS・バージョンでの成立条件、10月29日以降の全ベンダーの修正状況。
- **別件であること：** 10月29日に問題が公表された**CursorマーケットプレイスのClaude Code拡張機能の改ざん事故**とは、原因も攻撃経路も異なる。
