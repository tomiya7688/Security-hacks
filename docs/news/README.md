## ニュースの書き方

記事では、次の問いに答えます。

1. **何が起きた？** — 発表された事実を、普通の言葉で。
2. **自分にも関係ある？** — 対象となる製品・利用者・条件を明確に。
3. **何が危ない？** — 想定される被害と、その条件を混同しない。
4. **今、何をすればいい？** — やれることを具体的に。ただし無断で他人のシステムを試さない。
5. **どこまで分かっている？** — 未確認のことは未確認と書く。
6. **情報源は？** — 原則として開発元・公的機関・当事者の一次情報へのリンクを付ける。

**記事の公開日と、出来事の発生日は別物。** 「発表日」「確認日」を書き分けます。公式の重要度区分と編集者の感想も混ぜません。後日内容を直すときは確認日と修正内容を残します。

ニュースの量より、**根拠と対策の確かさ**を優先します。「誰でも被害に遭う」「すべて解決」といった断言はしません。

新しい記事を追加するときは、[ニュース記事のテンプレート](_TEMPLATE.md)と[全体の記事の書き方](../writing-guide.md)も参照してください。
